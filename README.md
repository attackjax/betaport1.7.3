Betaport ports the whole game from Beta 1.7.3 on Minecraft 26.1.2. 
The same terrain, caves, and biomes as Beta 1.7.3 for the same seed in a 128-block-tall overworld. 
Blocks, items and mobs Beta never had are switched off, worlds saved before are converted to Beta the first time each part of it loads, 
so back up any world you want to keep before opening it with the mod.

DISCLAIMER:
This mod requires a b1.7.3 installation to have been installed and run at least once for textures and sounds.
This mod does not ship with any Mojang AB assets. 

AI was used to automate tedious jobs.
