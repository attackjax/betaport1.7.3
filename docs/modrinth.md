# Betaport

Beta 1.7.3, running on Minecraft 26.1.2.

Every new world is a Beta world. Put in a seed from Beta 1.7.3 and you get the same world you
remember, block for block: terrain, caves, ores, trees, lakes, dungeons and the Nether, all
checked against Beta's own generator. The mobs, crafting, drops, lighting, water and lava,
farming, minecarts and boats follow Beta's rules, and anything Beta didn't have is switched off.

Textures and sounds come from your own copy of Beta 1.7.3. Nothing of Mojang's is included
in the mod, so play Beta 1.7.3 once in your launcher first and Betaport finds it on its own.
If it can't, it tells you at start-up and you can point it at the jar.

## Before you install

- **Back up your worlds.** Opening an existing world converts its blocks and items to Beta's
  as it loads, and there's no going back.
- Needs Fabric Loader 0.19.5 or newer, Fabric API and Java 25.
- Works with Sodium and Voxy. With Voxy, Beta's fog stretches out to Voxy's far terrain.
- For a server, put it on the server and in every player's game.
- The official launcher shares one mods folder across all Fabric versions, so give your
  26.1.2 profile its own game directory.

## Still rough

A few small things still differ from Beta, and the full list is in the README. Please report
anything that doesn't match how Beta played.

## Generative AI

Much of the code was written with a generative AI model, working from my directions and
checked against Beta 1.7.3 by the project's tests. The current icon is AI-generated too and
will be replaced with a hand-drawn one.
